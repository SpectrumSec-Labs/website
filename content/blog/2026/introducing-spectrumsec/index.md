Welcome. This blog is where the SpectrumSec team writes up the things we learn on
engagements — attack techniques worth knowing about, defensive patterns that work,
and the occasional opinion about the state of the industry.

## What to expect

- **Field notes.** Anonymised, sanitised lessons from real testing.
- **Practical guidance.** Hardening steps you can apply the same week.
- **Research.** Longer pieces when we find something worth a deep dive.

## How this blog is built

Every post is a Markdown file in Git. Changes ship through pull requests with review,
the site is a static build with a strict content security policy, and there is no
third-party script anywhere on this page. If you find a security issue with the site
itself, our [disclosure policy](/legal/security-policy/) explains how to report it.
